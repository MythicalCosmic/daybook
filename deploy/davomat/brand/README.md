# Davomat's mark

A white D (for Davomat) with a check cut into it (someone came), on an indigo tile lit from the
top. The shapes and colors are defined once in `dashboard/src/core/brand.ts` (`DAVOMAT_MARK`); the
app draws the favicon, the sidebar, the sign-in page and the first paint from them.

| File | For |
|---|---|
| `davomat-mark.svg` | documents, slides, printing (any size) |
| `davomat-mark-512.png`, `davomat-mark-180.png` | places that want a picture file |
| `telegram-avatar.png` | the bot's picture: @BotFather › `/setuserpic` (Telegram shows it in a circle) |

An organization's own logo (Settings › Organization) replaces the mark in the app.
