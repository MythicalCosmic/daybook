# Установка Davomat

Davomat — отдельное приложение для учёта посещаемости по Face ID: терминалы распознавания лиц
Hikvision у дверей, приходы в браузере в реальном времени с фото каждого сканирования, графики,
опоздания, табели, отчёты и Telegram-бот. Один сервер обслуживает одну организацию (со всеми её
филиалами).

Это руководство для того, кто настраивает сервер. Тот, кто затем ведёт организацию, читает
[ADMIN.md](ADMIN.md), а если что-то пошло не так — [TROUBLESHOOTING.md](TROUBLESHOOTING.md).

## 1. Что понадобится

| | |
|---|---|
| Сервер | Ubuntu 22.04 или 24.04 с root-доступом по SSH (любой VPS или компьютер в офисе) |
| Ресурсы | 2 vCPU, 4 ГБ памяти, 40 ГБ диска (на несколько сотен сотрудников; фото и резервные копии со временем растут) |
| Порты | 80 и 443 открыты для интернета (или для локальной сети, см. раздел 7) |
| Адрес | доменное имя, DNS-запись `A` которого указывает на сервер, например `davomat.example.uz`. Если домена нет, подойдёт `<server IP>.nip.io` (например, `203.0.113.10.nip.io`) — с настоящим HTTPS-сертификатом |
| Терминалы | терминалы распознавания лиц Hikvision (MinMoe: DS-K1T341AMF, DS-K1T341, DS-K1T342, DS-K1T343, DS-K1T671, DS-K1T804…), из сети которых сервер доступен по порту 80 |
| Telegram | по желанию: бот, созданный через @BotFather (ADMIN.md, раздел 7) |

Если Docker не установлен, установщик поставит его сам. Больше ничего вручную ставить не нужно.

**Облачные файрволы.** У некоторых провайдеров (AWS, Google Cloud, Hetzner Cloud, Oracle…) перед
сервером стоит собственный файрвол: откройте TCP 80, TCP 443 и UDP 443 и в нём.

## 2. Разместите код на сервере

Либо клонируйте репозиторий:

```bash
git clone <repository URL> /opt/davomat
```

либо скопируйте релиз, подготовленный на другом компьютере, и распакуйте его:

```bash
# на компьютере с кодом: релиз того коммита, который нужно установить
git archive --format=tar.gz --prefix=davomat/ -o davomat.tar.gz HEAD
scp davomat.tar.gz root@<server>:/root/

# на сервере
mkdir -p /opt/davomat
tar -xzf /root/davomat.tar.gz -C /opt/davomat --strip-components=1
```

`/opt/davomat` — лишь пример: подойдёт любая папка, и все команды ниже выполняются из неё.

## 3. Запустите установщик

Сборка занимает 5–15 минут. Запускайте установщик внутри `tmux` (или `screen`), чтобы обрыв
SSH-соединения его не остановил:

```bash
cd /opt/davomat
tmux new -s davomat          # если tmux нет: apt-get install tmux
bash deploy/davomat/install.sh
```

Он задаст два вопроса:

1. **Где будут открывать Davomat**: в интернете (по умолчанию) или только в локальной сети.
2. **Доменное имя**: нажмите Enter, чтобы использовать `<server IP>.nip.io`, или введите свой домен.

Остальное он сделает сам:

- проверит сервер (память, диск, часы) и, если Docker не установлен, поставит его официальным
  скриптом Docker (предварительно спросив);
- запишет настройки в `/opt/davomat/.env` (права доступа 600) с только что созданными ключами;
- откроет порты 80 и 443 в `ufw`, если файрвол включён (предварительно спросив);
- соберёт образ, запустит всё и дождётся, пока сайт не ответит по HTTPS (Caddy сам получает
  сертификат от Let’s Encrypt);
- выведет адрес, который нужно открыть, и где лежат логи и резервные копии.

```
==> Davomat is running
    Open https://203.0.113.10.nip.io/ in a browser to set up your organization.
    Face ID terminals post to 203.0.113.10 over HTTP, port 80: Face ID › Add a terminal shows the exact values.
```

Повторный запуск установщика безопасен: он сохраняет существующий `.env` (никогда его не
перезаписывает) и запускает только то, что не работает. Его лог:
`/var/log/davomat/install-<date>.log`.

### Без вопросов

```bash
bash deploy/davomat/install.sh --yes --domain davomat.example.uz
```

а чтобы заодно создать организацию — здесь же, а не в браузере:

```bash
bash deploy/davomat/install.sh --yes --domain davomat.example.uz \
  --organization "Namuna MChJ" --admin-username admin --admin-password '<a strong password>' \
  --timezone Asia/Tashkent --language uz
```

| Параметр | Что делает |
|---|---|
| `--domain NAME` | имя сайта (по умолчанию: `<public IP>.nip.io`) |
| `--lan [ADDRESS]` | сервер, доступный только из локальной сети (раздел 7) |
| `--http-only` | обычный HTTP — для пробного запуска на самом компьютере по адресу `http://localhost` |
| `--device-host HOST` | адрес, на который терминалы отправляют события (по умолчанию: публичный IP сервера) |
| `--http-port N`, `--https-port N` | другие порты вместо 80 и 443 (терминалам и сертификатам нужен порт 80) |
| `--organization`, `--admin-username`, `--admin-password`, `--admin-first-name`, `--admin-last-name`, `--timezone`, `--language` | сразу создать организацию (`manage.py davomat_init`) |
| `--image FILE` | использовать готовый образ вместо сборки (раздел 8) |
| `--no-start` | записать `.env` и остановиться |
| `-y`, `--yes` | без вопросов: значения по умолчанию, Docker устанавливается, если его нет |

## 4. Первый запуск

Откройте адрес в браузере. Только что установленный Davomat откроет **страницу настройки**:

1. **Организация**: название (видно на странице входа, в отчётах и в Telegram), часовой пояс (по
   нему считаются приходы и опоздания) и язык.
2. **Ваш аккаунт**: имя, логин и пароль администратора (не менее 8 символов, не простое слово и не
   только цифры).
3. **Готово**: вы вошли в систему. Добавьте первый терминал (ADMIN.md, раздел 4).

Страница настройки срабатывает один раз: после этого по адресу открывается страница входа.

## 5. Что работает на сервере

Всё работает в Docker Compose (`docker-compose.davomat.yml`, проект `davomat`):

| Сервис | Что делает |
|---|---|
| `caddy` | HTTPS и сертификат; обычный HTTP для терминалов; логотипы и фото сотрудников |
| `backend` | сам Davomat (Django и gunicorn): веб-приложение, API, события терминалов. При запуске применяет миграции базы данных |
| `worker` | фоновые задачи: сообщения в Telegram, выгрузки, отчёты |
| `beat` | расписание: сводка за день, опоздания, очистка |
| `bot` | Telegram-бот организации (ждёт, пока в разделе Настройки › Telegram не вставят токен) |
| `db`, `redis` | PostgreSQL 18 и Redis |
| `backup` | ночное резервное копирование (раздел 6) |

Где что находится:

| | |
|---|---|
| Настройки | `/opt/davomat/.env` (права доступа 600). **Храните копию в надёжном месте**: ключи из него невозможно создать заново |
| Резервные копии | `/opt/davomat/backups/` |
| Логи установки и обновлений | `/var/log/davomat/` |
| Данные | тома Docker: `davomat_pgdata` (база данных), `davomat_media` (логотипы, фото сотрудников), `davomat_private_media` (снимки сканирований, выгрузки), `davomat_caddy_data` (сертификаты) |

Повседневные команды (из `/opt/davomat`):

```bash
bash deploy/davomat/status.sh                     # общее состояние (только чтение)
docker compose -f docker-compose.davomat.yml ps   # сервисы
docker compose -f docker-compose.davomat.yml logs -f backend     # лог сервиса
docker compose -f docker-compose.davomat.yml exec backend python manage.py <command>
```

## 6. Обновления и резервные копии

### Обновление

```bash
cd /opt/davomat
bash deploy/davomat/update.sh                          # копия из git: git pull
bash deploy/davomat/update.sh --from /root/davomat.tar.gz   # архив релиза
```

Скрипт сначала делает резервную копию, получает новый код (`.env`, резервные копии и логи не
затрагиваются), собирает новый образ, перезапускает сервисы, применяет миграции, перезапускает
Caddy, если изменился его файл, и ждёт, пока сайт не ответит. Если новая версия не запускается, он
выводит, как вернуться назад: предыдущий код, `update.sh --here --no-backup` и `restore.sh` с
резервной копией, которую он сделал. `update.sh --here` пересобирает и перезапускает то, что уже
есть (например, после правки `.env`).

### Резервные копии

Каждую ночь в 02:30 (по ташкентскому времени; `BACKUP_TIME` и `BACKUP_TZ` в `.env`) сервис
`backup` создаёт папку `backups/<date>_<time>-nightly/`, в которой:

- `db.sql.gz`: вся база данных;
- `media.tgz`: логотипы и фото сотрудников;
- `private_media.tgz`: снимки сканирований и выгрузки;
- `info.txt`: когда и из чего сделана копия.

Хранятся копии за последние 14 дней (`BACKUP_KEEP_DAYS`). Прочитать их может только root: в них
имена, фото и посещаемость всех сотрудников.

```bash
bash deploy/davomat/backup.sh            # резервная копия прямо сейчас (backups/<date>_<time>-manual/)
scp -r root@<server>:/opt/davomat/backups/<folder> .    # скопировать одну копию с сервера
```

**Регулярно копируйте резервные копии за пределы сервера** (и храните их зашифрованными): копия на
том же диске погибнет вместе с диском.

### Восстановление

```bash
bash deploy/davomat/restore.sh backups/2026-11-10_023000-nightly
```

Скрипт попросит ввести `restore`, сделает страховочную копию текущего состояния, остановит Davomat,
вернёт базу данных и файлы из этой копии и снова всё запустит. Всё, что произошло после этой
копии, будет потеряно.

### Переезд на новый сервер

1. На старом сервере: `bash deploy/davomat/backup.sh`, затем скопируйте папку резервной копии
   **и файл `.env`** на новый сервер.
2. На новом сервере: разместите код в `/opt/davomat` (раздел 2), скопируйте старый `.env` в
   `/opt/davomat/.env` (`chmod 600`) и, если адрес меняется, измените `DOMAIN`,
   `DJANGO_ALLOWED_HOSTS`, `DASHBOARD_URL` и `PUBLIC_DEVICE_HOST`.
3. `bash deploy/davomat/install.sh` (он сохранит этот `.env`), затем
   `bash deploy/davomat/restore.sh <the backup folder>`.
4. Если адрес изменился, направьте терминалы на новый адрес (ADMIN.md, раздел 4).

Ключи в `.env` должны быть теми же, с которыми сделана резервная копия. Без них токен Telegram-бота
не прочитать, и его придётся вставить заново.

## 7. Сервер в локальной сети

Если сервер стоит в офисе и из интернета к нему не попасть, публичный сертификат получить нельзя.
Установите его в режиме LAN:

```bash
bash deploy/davomat/install.sh --lan                # LAN-адрес сервера определяется автоматически
bash deploy/davomat/install.sh --lan 192.168.1.10   # или задаётся вручную
```

Тогда Davomat отвечает по адресу `https://192.168.1.10/` с собственным сертификатом. Браузеры один
раз покажут предупреждение («not private», то есть подключение не защищено): выберите Advanced ›
Continue («Дополнительные» › «Перейти на сайт»). Чтобы предупреждение больше не появлялось,
установите корневой сертификат Caddy на офисные компьютеры:

```bash
docker compose -f docker-compose.davomat.yml exec caddy cat /data/caddy/pki/authorities/local/root.crt > davomat-root.crt
```

(Windows: дважды щёлкните файл › Install Certificate («Установить сертификат») › Local Machine
(«Локальный компьютер») › Trusted Root Certification Authorities («Доверенные корневые центры
сертификации»).) Терминалы по-прежнему отправляют события по обычному HTTP. Закрепите за сервером
постоянный адрес в роутере (резервирование DHCP), иначе терминалы его потеряют.

`--http-only` отдаёт всё по обычному HTTP. Это только для пробного запуска на самом компьютере по
адресу `http://localhost`: по обычному HTTP браузеры сохраняют вход только для localhost.

## 8. Готовый образ

Для сборки нужно около 2 ГБ памяти и интернет (Docker Hub, npm, PyPI). На маленьком сервере или на
сервере без интернета соберите образ на другом компьютере и скопируйте его:

```bash
# на компьютере для сборки, из копии того же коммита
docker build -t davomat:latest .
docker save davomat:latest | gzip > davomat-image.tar.gz
scp davomat-image.tar.gz root@<server>:/root/

# на сервере
bash deploy/davomat/install.sh --image /root/davomat-image.tar.gz
bash deploy/davomat/update.sh --from /root/davomat.tar.gz --image /root/davomat-image.tar.gz   # последующие обновления
```

## 9. Безопасность

- `.env` хранит ключи: права доступа 600, только root. Никогда не кладите его в git и не
  отправляйте в чат.
- Открытыми должны быть только порты 80 и 443 (и SSH). PostgreSQL и Redis снаружи никогда не
  доступны.
- Для root используйте SSH-ключи, а не пароли, и регулярно обновляйте Ubuntu
  (`apt-get update && apt-get upgrade` или `unattended-upgrades`).
- Каждый терминал отправляет события на адрес со своим секретным кодом: относитесь к этому адресу
  как к паролю (новый код выдаётся одним нажатием на странице терминала).
- Когда HTTPS заработает, `DJANGO_SECURE_HSTS_SECONDS=31536000` в `.env` и
  `bash deploy/davomat/update.sh --here` заставят браузеры всегда использовать HTTPS.

## 10. Попробовать на одном компьютере

`deploy/davomat/demo.sh` запускает всю систему на ноутбуке или настольном компьютере с Docker (без
прав root) отдельным проектом со своими данными по адресу `http://localhost:18080` и заполняет её
примером организации (вход: `admin`, пароль `Namuna-2026`):

```bash
bash deploy/davomat/demo.sh up        # при необходимости собрать образ, запустить, добавить пример
bash deploy/davomat/demo.sh down      # остановить (данные остаются; up запускает снова)
bash deploy/davomat/demo.sh wipe      # остановить и удалить данные
```

`up --no-seed` запускает без примера (откроется страница настройки), с `up --lan` терминал в той же
сети тоже сможет отправлять ему события (на терминале порт 18080), `rebuild` берёт новый код,
`seed` заменяет пример новым. Настоящую установку на том же компьютере он никогда не затрагивает.
